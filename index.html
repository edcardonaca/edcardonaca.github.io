Proyectos
Trabajo aplicado
Proyectos con datos reales, código abierto y resultados concretos.
PROYECTO 01
Análisis de Correlación: Commodities Energéticos vs. Cartera de Activos
¿Cuánto pierde una cartera diversificada si el WTI cae un 10%? Análisis estadístico end-to-end sobre 1,509 días de datos: correlación de Pearson, regresión OLS, correlación rolling de 90 días y simulador interactivo en Power BI.
→ Impacto total estimado: −3.45% ante WTI −10%
Python pandas scipy statsmodels Power BI DAX yfinance
→
PROYECTO 02
Análisis de Funnel y Canales de Marketing con SQL
¿Dónde pierde clientes un e-commerce en el camino a la compra? 9 queries de SQL sobre el dataset Maven Fuzzy Factory: fundamentos de negocio, análisis de canales con LEFT JOIN, y funnel de conversión con window functions. Cierra con dashboard interactivo en Power BI.
→ Mayor caída del funnel: -54.83% (producto → carrito)
SQL DuckDB Window Functions Power BI Python
→
PROYECTO 03
Consolidador de Reportes con Resumen Ejecutivo por IA
Pipeline en Python que consolida Excels de ventas con formatos inconsistentes entre sucursales, calcula KPIs, detecta alertas automáticamente y genera un resumen ejecutivo redactado por IA — listo para enviarse por correo sin intervención manual.
→ Detectó automáticamente 2 sucursales con caída fuerte (-24.8% y -21.1%)
Python pandas Gemini API openpyxl Automatización
